# Example — video 7: "a perfect script still sounds unnatural" (approved, 4K delivered 2026-10-27)

111 s, one take used whole. The edit the user approved after rejecting a first version whose B-roll was "random"
and opaque. Copy its **level of finish** and its **way of thinking**, not its content.

- `BRIEF.md` — message, look, the throughline ("one frosted workflow, start to finish"), the beat table, music.
- `index.html` — the full project as delivered (set to 2880×2160; TRACK, SHOTS, hosts, 3 live windows, 83 SFX).
- `compositions/` — every piece:
  - `ov-a…ov-e` captions (generated by `caption_script.py`) · `ov-behind` PERFECT / EASIER / DONE
  - `fl-a` the script workflow: appears, fails, returns, swaps Voiceover for On camera, dives in
  - `sc-watch` rack scene: frosted player + live take; 1.6× "too fast"; waveform gaps close "no spaces"
  - `fl-e` you → viewer: Understood ✓ / Just told
  - `sc-comm` rack scene: switchboard of real frames (words, hands, silences, expression) → 30–100%
  - `fl-fix` "expression" bracket; then the fixed workflow with 0.8×, problem labels cleared by Re-record, 1×→30×
  - `sc-anchor` rack scene: this video's own script → one sentence → the live camera ✓; word-by-word in red
  - `fl-end` my videos (Script toggled off by "me"); the next video at 62%
- `frames/` — stills from the delivered video at key moments (look at these to calibrate size, translucency,
  placement).
- `caption_script.py`, `score_script.py`, `mix.json` — captions and the music cue plan as used.

Assets (the take, mattes, fonts, SFX, frames of the speaker) are not included; the template has the fonts and SFX.
