# The kit (HFKit) — API reference

Everything lives in `template/index.html`: the CSS (type, glass, flow pieces), `window.HFKit` (builders) in
the `<head>`, and the camera/main timeline at the end of `<body>`. Compositions call `window.HFKit` (as `K`).
All coordinates are **1440×1080 world px**; all times are **composition-local seconds** unless noted.

## 1. Project layout and the composition skeleton

```
index.html                  kit + camera + hosts (one <div class="ovhost|schost clip" data-composition-src=…> per comp)
compositions/ov-a.html …    caption hosts INSIDE #cam (ride the camera); filled by caption_script.py
compositions/ov-behind.html hero words behind the head (paired with matte <video>s in #trk-m)
compositions/fl-*.html      screen-locked frosted cards (outside #punch, so the glass can blur the footage)
compositions/sc-*.html      rack-focus scenes (screen-locked; index.html calls rack(t0, t1))
assets/aroll-cut.mp4        the whole take (one file; the user's cutting step makes it)
assets/matte/*.webm         speaker cut-outs for the hero words
assets/frames/*.jpg         real frames of the speaker (≈600×600 crops from the 4K source) for photo nodes
caption_script.py, scripts/captions.py, transcript-snap.json
```

Track indices: A-roll 0 · mattes 1 · ov-behind 2 · captions 4 · fl-* 5 · sc-* 6 · portal videos 8 · SFX 10–15 ·
music 20. Host: `<div id="fl-x" class="ovhost clip" data-composition-id="fl-x" data-composition-src="compositions/fl-x.html" data-start="S" data-duration="D" data-track-index="5" data-width="1440" data-height="1080"></div>`
(alternate track 5/6 so overlapping hosts sit on different tracks; captions on 4, behind-words on 2).

Composition skeleton:
```html
<template>
  <style> #root { position: absolute; inset: 0; overflow: visible; } </style>
  <div id="root" data-composition-id="fl-x" data-width="1440" data-height="1080">
    <div id="fx-wrap" style="position: absolute; inset: 0"></div>
  </div>
  <script>
    (function () {
      const K = window.HFKit, el = K.el;
      const tl = gsap.timeline({ paused: true });
      const W = document.getElementById("fx-wrap");
      const O = 38.3;                                  // = the host's data-start
      const T = (g) => +(g - O).toFixed(2);           // global (transcript) seconds → local
      /* … build … */
      window.__timelines["fl-x"] = tl;
    })();
  </script>
</template>
```
IDs must be unique across the whole document (all compositions share one page) — prefix them per composition.

## 2. Text

### `K.text(tl, parent, spec)` → the group element
```js
K.text(tl, S, { shot: "s4", x: 970, y: 84, a: "tc",
  lines: [ { s: 58, w: [["this is a problem", 13.84]] },
           { s: 124, w: [["faced", 15.18, "b", "m"]] } ],
  out: 15.8, outMode: "fade" });
```
- `x, y`: screen px at the start of `shot` (converted into the camera plane so the stack rides the dolly). Omit
  `shot` for screen-locked text (scene headlines: `{ x: 100, y: 64, a: "tl" }`).
- `a`: anchor `tl | tc | tr | cl | cc | …` (vertical t/c/b + horizontal l/c/r).
- `lines[].s`: size px; `lines[].w`: `[text, time, colour?, "m"?]` — colour `"b"` accent blue, `"s"` serif
  italic blue (headlines), `"x"` white, `"i"` ink; `"m"` adds the highlighter swipe.
- `out` / `outMode`: `"fade"` (0.16s fade + blur) or `"cut"`.
- Options: `tilt: true` (3D lean toward the face — only when the camera leans), `ry`, `rot`, `dir`, `id`.
Captions are normally generated by `caption_script.py` (`scripts/captions.py`), not written by hand.

### `K.roller(tl, parent, {x, y, size, values, times, a, cls, color})` — odometer
`values: ["1.0", "1.6"]`, `times: [0, T(35.2)]` — each column is a strip of the characters it ever shows and
rolls right-to-left at each time. Shorter values are left-padded with a blank column. Put non-digit symbols
(×, %) OUTSIDE the roller if they render clipped (`%` has its own wide column and is fine).

### `K.arc(tl, parent, {text, cx, cy, r, s, t, a0, spacing, stagger, c, out})` — text on an arc (rarely used).

## 3. Placing things in the camera plane

- `K.ws(shot, sx, sy)` → `{x, y, k}`: world coordinates (and scale factor) of a screen point at a shot's start.
- `K.widget(tl, node, {shot, x, y, zoom, t, out, fade})`: places a screen-designed element into the camera
  plane at a shot's start and pops it in/out. (Cards on the footage are now screen-locked fl-* comps instead.)
- `K.SHOTS`, `K.FACE`, `K.frame(s, sx, sy)` — the shot table (see `references/03-camera-and-face-tracking.md`).

## 4. Frosted flow pieces

### `K.fcard(parent, {x, y, w, h})` → `{ box, inner }`
The frosted rim (`.fz`) and the see-through panel (`.fz-in`, inset 14). Put content in `inner` (its origin is
`x+14, y+14` on screen — anything you place inside uses inner coordinates). A small header: an element with
class `fz-hd` inside `inner` (`left: 30px; top: 26px`, one `<em>` serif word). A progress bar inside a step: an
element with class `fill` appended to the pill (`width` = pill width, animate `scaleX`). The glass is tuned for
bright outdoor footage; on dark footage raise `.fz-in` to ~0.7 white so the dark text keeps its contrast, and
check frames. Grow it with `tl.to(card.box, { height: H, duration: 0.55, ease: "expo.out" }, t)`.
After an entrance blur, `tl.set(card.box, { filter: "none" }, t + 0.75)`.

### `K.fpill(tl, parent, {x, y, label, state, a, w, img, icon})` → api
A step. `a: "c"` centres on x (default) or `"l"` left edge; `w` fixed width (use one width per card, e.g. 440).
Labels are 1–3 words: at w 440 about 328px of text fits (~16 characters at 35px) — no wrapping.
`state`: `todo | run | ok | err | off` (initial). `img`: a photo icon (`icon: "img"` to start on it).
- `.to(state, t, label?, iconKey?)` — cross-fade to a new state at t; optional new label; `iconKey` to keep a
  custom icon (e.g. `"img"`). `ok`/`err` add a small settle pop; `off` strikes, dims, blurs.
- `.label(text, t)` — swap the label (old slides up and blurs, new rises).
- `.spin(t0, t1)` — rotate the spinner while running (chain after `.to("run", t0)`).
- `.el` — the element (to fade/move/dim it); `.ico` — the icon layers.
```js
const P = K.fpill(tl, card.inner, { x: 26, y: 30, w: 440, a: "l", label: "Write it down" });
P.to("run", T(62.5)).spin(T(62.5), T(63.26));
P.to("ok", T(63.26));
```

### `K.fchip(tl, parent, {x, y, text, cls, dot, a, t, out})` → element
A dark state label (`cls: "lite"` white, `"blue"` accent). Vertically centred on y; `a` = l/c/r horizontal
anchor; `dot: true` adds a red dot. `text` may contain HTML (e.g. a roller span). **Pass `t`** — without it the
chip stays invisible (it starts at opacity 0).

### `K.flink(tl, svg, {pts, dash, r, color, w, dot0, dot1, t, d})` → `{ g, path, len }`
A connector through `pts` (orthogonal paths get rounded corners of radius `r`, default 18). `dash: true`
(7/9) or a dasharray string. Draws on from the first point at `t` over `d`; end dots pop. Fade `link.g` to hide.

### `K.fsvg(parent, w, h)` → an `<svg>` overlay to draw connectors into (one inside a card, one screen-level).

### `K.fcursor(tl, parent, {name, color, x, y})` → `{ el, show(t), moveTo(x, y, t, d), click(t), hide(t) }`
A named multiplayer cursor ("you", "me"). Coordinates are the arrow tip.

### `K.fsel(tl, parent, {x, y, w, h})` → `{ el, show(t), to({x, y, w, h}, t, d), hide(t) }`
A selection box with four handles; `to` snaps it (expo.inOut) — whole → part.

### `K.ftoggle(tl, parent, {x, y, on})` → `{ el, set(on, t) }`

### `K.fface(parent, {x, y, d, src | icon})` → element
A round photo node centred at x, y with diameter d (`src` a real frame; or `icon: "user"` for an outlined icon).

## 5. Icons, stages, rng

- `K.iconSvg(name)` → `<svg>` string (stroke icons): play, search, bulb, users, user, key, sliders, briefcase,
  repeat, scissors, pen, anchor, megaphone, doc, film, check, layers, arrowUp, upload, image, music, type,
  battery, zap, send, heart, palette, flask, flame, trend, link, sparkles, message, unlock, clock, eye, drop,
  ticket, net, square, quote, mic, video, pause, smile. In your own containers give the svg a stroke colour.
- `K.icon(tl, parent, {i, x, y, size, blue, t, out})` — a round icon chip.
- `K.darkStage(parent, dots)`, `K.paperStage(parent)`, `K.gridStage(parent)`, `K.skyStage(parent)` — fallback
  full-screen grounds (rack focus is preferred).
- `K.rng(seed)` → deterministic random numbers in [0, 1) (never `Math.random`).

## 6. The main timeline (end of `index.html`)

- **Shots:** every `SHOTS` row is turned into its arrival (`whip | cut | move | rack`) + one dolly-out.
- **Tracking:** `/*TRACK:start*/ const TRACK = [...]; /*TRACK:end*/` (written by `scripts/face_track.py`);
  `.trk` wrappers follow it, clamped to the overscan. Empty `[]` = no tracking.
- **Punch-ins:** `const PUNCH = [t, …]` — +8% around the face, released at the next shot.
- **`rack(t0, t1)`:** blur the camera behind a scene (call once per sc-*). t0 = the previous shot's `end`, t1 =
  the next shot's `t` (that shot uses `in: "rack"`).
- **`portal(id, t0, t1)`:** fade a live window in/out with its scene's card. The portal `<div class="portal">`
  holds a muted `<video>` of `assets/aroll-cut.mp4` with `data-start = data-media-start` (in sync with the take).
- **End:** eases to black over the last 0.45s.

## 7. Recipes

**A step list that runs as it is described** — see `template/compositions/fl-example.html`.

**A label pinned to a step** (dashed, from the card edge outward):
```js
K.flink(tl, svgOut, { pts: [[cardX + 14 + 26 + 440, midY], [596, midY]], dash: true, dot0: true, t, d: 0.3 });
K.fchip(tl, W, { x: 600, y: midY, text: "too fast", dot: true, t: t + 0.1 });
```

**Replace a step** (don't do X, do Y):
```js
P[1].label("Voiceover", t0); P[1].to("off", t1);                               // strike + dim
tl.to(P[1].el, { x: 40, opacity: 0, filter: "blur(8px)", duration: 0.4, ease: "power2.in" }, t2);
tl.fromTo(Y.el, { opacity: 0, x: -40 }, { opacity: 1, x: 0, duration: 0.55, ease: "expo.out", immediateRender: false }, t2 + 0.3);
```

**Focus by dimming:** `tl.to(others, { opacity: 0.32, filter: "blur(1.5px)", duration: 0.45, ease: "power2.out" }, t)`.

**A counter inside a step:** append a dark badge to `P.el` (absolute, right 16, top 15) holding a roller span
and a static "×"; values `["1", "10", "15", "20", "30"]` on the spoken numbers.

**A switchboard** (inputs → toggles → output %): see `examples/video-7-script-to-speaking/compositions/sc-comm.html`.

**Whole → one sentence → to the camera**: see `examples/video-7-script-to-speaking/compositions/sc-anchor.html`.
