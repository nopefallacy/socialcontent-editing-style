# The user's reference screenshots

These are the user's moodboard — third-party UI shots they collected (not their own work), so the images are
**not included in this repo**; the descriptions below are written to stand on their own. If the images are
available locally (the user keeps them in `socialcontent/tools/refs/`, or in this folder, git-ignored), look at
one before using its piece. They define the B-roll vocabulary: light, refined interface pieces that *do* one
thing. Copy the grammar and the restraint, never the branding or colours.
